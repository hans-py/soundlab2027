曲を入れるフォルダです。1曲目は 01、2曲目は 02 … 7曲目は 07 です。
各フォルダに、次のファイルを入れます（ファイル名は半角のこの通りにしてください）。

  info.txt     曲名（必須）。「曲名:」を空にすると、その曲は表示されません
  audio.mp3    曲（必須）。これがないと表示されません
  video.mp4    MV（なければ入れなくてOK。MVタブが押せなくなります）
  lyrics.txt   歌詞（なければ入れなくてOK。歌詞の欄が消えます）
  credits.txt  作曲・イラスト・MV などの担当者（なければ入れなくてOK）

入れたあと GitHub に push すると、数分でサイトに反映されます。
書き方は、info.txt と credits.txt の上の方にあるメモを見てください。
